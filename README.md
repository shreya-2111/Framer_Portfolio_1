# Alex Carter – Premium Portfolio

A premium, immersive developer portfolio built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, GSAP, and React Three Fiber.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- GSAP

## Getting Started

```bash
npm install
npm run dev
```

## Customization

All portfolio content lives in one file:

```
src/constants/data.ts
```

Edit `personal`, `skills`, `projects`, `experience`, `testimonials`, and `socials` to make it yours.

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

```bash
npx vercel
```

For production deployment:

```bash
npx vercel --prod
```
